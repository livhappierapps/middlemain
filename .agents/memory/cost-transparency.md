---
name: Cost transparency
description: Dev's project-wide instruction to warn before actions that may incur charges.
---

Warn Dev before taking any action that may incur any cost, including external AI/search API usage and build or submission services. Do not trigger paid usage without giving clear notice first.

**Why:** Dev explicitly requested advance notice of any costs.

**How to apply:** Before calling a potentially billable service or starting a build/submission that can charge, state the possible charge and wait for approval when the action itself would incur it. Also disclose likely provider charges for features users may invoke later.
